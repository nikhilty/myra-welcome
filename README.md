# Myra’s Welcome Reception — GitHub Pages

A single-page, mobile-friendly invitation website with an animated reveal, family photo story, event details, directions, add-to-calendar, and WhatsApp-style RSVP preparation.

**Event:** Sunday, November 29, 2026 at 12:00 PM IST  
**Venue:** Silver Emerald Banquet, 3rd Floor, AVS City Palace, Raj Nagar Extension, opposite Sangwan Heights, Ghaziabad, Uttar Pradesh 201007, India.

## Publish to a personal GitHub account

1. Sign in to a **personal** GitHub account. Create a new **public** repository named `myra-welcome`. Make sure **Owner** is your username, **not `Affirm`**.
2. Open the new repository → **Add file → Upload files**. Upload `index.html`, `cover.jpg`, and `.nojekyll` from this extracted folder. Commit to `main`.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main**, folder to **/(root)**, and **Save**.
4. After GitHub finishes publishing, your address should be `https://YOUR-USERNAME.github.io/myra-welcome/`. For `nikhilty`, the expected address is `https://nikhilty.github.io/myra-welcome/`.
5. Visit the link in a private browser window and test the directions, calendar, photos, and RSVP before sharing with guests.

## Before sending guests the link

- **Important privacy note:** GitHub Pages is a public website; photos of Myra and venue details on the page can be viewed by anyone with the link, even when search engine indexing is discouraged. Do not assume the site is access-controlled.
- **RSVP:** The current page does not have a host WhatsApp number set and does not store RSVPs in a database. Guests can prepare or share a reply. Configure a WhatsApp number before publishing if you want the replies to open addressed to you.
- **Edit invitation:** The page’s in-browser editor stores changes *on that visitor's device*; it does not change the published website. Update the source `index.html` and push changes to GitHub to update the public page. If your preferred repository or username differs from `nikhilty/myra-welcome`, also edit the `og:url` and `og:image` meta tags in the `<head>` of `index.html`.
